# Sub2API standalone deployment

This directory is a self-contained Docker Compose stack for Sub2API behind Traefik.

## What it exposes

- `SUB2API_HOST` for API clients and NewAPI upstream traffic
- `SUB2API_ADMIN_HOST` for the browser-facing admin UI
- HTTPS is terminated by Traefik with automatic Let's Encrypt certificates

## Files

- `docker-compose.yml`
- `.env.example`

## First setup

```bash
cp .env.example .env
# Run this once per required secret listed below, then write them into .env.
openssl rand -hex 32
${EDITOR:-vi} .env
mkdir -p data postgres_data redis_data letsencrypt
touch letsencrypt/acme.json
chmod 600 letsencrypt/acme.json
docker compose config >/dev/null
docker compose up -d
```

## Required values

Set these before first start:

- `ACME_EMAIL`
- `SUB2API_HOST`
- `SUB2API_ADMIN_HOST`
- `SUB2API_IMAGE_TAG` (`latest` by default; pin a release tag for stricter change control)
- `POSTGRES_PASSWORD`
- `REDIS_PASSWORD`
- `JWT_SECRET`
- `TOTP_ENCRYPTION_KEY`
- `ADMIN_PASSWORD`

Generate secrets with:

```bash
openssl rand -hex 32
```

`SERVER_FRONTEND_URL` is derived from `SUB2API_ADMIN_HOST` inside the compose file.

## Recommended routing

- `https://sub2api.example.com/v1` for NewAPI or other OpenAI-compatible clients
- `https://admin.sub2api.example.com/` for human admin login

Both hostnames point to the same Sub2API container. The app's own auth protects the admin UI; the API uses Sub2API API keys.

## Operations

Upgrade:

```bash
docker compose pull
docker compose up -d
```

Back up or migrate the deployment as one directory while stopped:

```bash
docker compose down
cd ..
tar czf sub2api-deploy.tar.gz sub2api/
cd sub2api
docker compose up -d
```

Include `.env`, `data/`, `postgres_data/`, `redis_data/`, and `letsencrypt/` in server backups. `data/config.yaml` contains the generated Sub2API runtime config and secrets, so do not delete it after first start.

## Notes

- Port `80` must be open for ACME HTTP-01 validation.
- Port `443` must be open for normal traffic.
- DNS `A`/`AAAA` records for both hostnames must point to this server before the first ACME request.
- `data/config.yaml` is generated by Sub2API auto-setup on first start.
- `SERVER_TRUSTED_PROXIES` is derived from `SUB2API_PROXY_SUBNET`.
- If the default Docker subnets collide with another deployment, change both subnet values before first start.
- URL allowlist is enabled by default. Add required upstream domains to `SECURITY_URL_ALLOWLIST_UPSTREAM_HOSTS` instead of disabling it.
- If an upstream or proxy URL uses an internal host/IP, explicitly add that host or adjust the private-host setting only for a trusted network.
- If you want a different host layout, keep the same Traefik labels and edit the two host env vars.
